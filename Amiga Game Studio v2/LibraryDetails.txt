  Amiga-e-Grimoire <<Game Development Kit>>
---------------------------------------------

Here are the details of the Game Development Kit that will be developed to be used with e-grimoire to bring to Amiga a full software development
kit that is native compatible, and that may allow an easy importation of other basic languages.

Datas used by Amiga-e-Grimoire are under instances. This mean you can open more than one application that'll use Amiga-e-Grimoire at the same time. The current amount of application that can cohabit in memory is actually set to 8.

Setup Details :
---------------
- Open the AEG_Setup.library will not initialize the Amiga Game Studio system.
- When the AEG_Setup.library method "Constructor" is called, an appContext (or InstanceID) is generated and Amiga Game Studio system is initialized.
- AEG_Setup.library method 'Constructor' will open all the AGS secondaries library using the appContext to instantiate the application.
- the appContext is returned by the AEG_Setup.library "Constructor" method call
- All the methods that will be developed in e-Grimoire, and that'll use AGS will require the appContext as 1st parameter excepted the following ones:
      * AEG_Setup.library/Constructor
      * AEG_HardwareDetextor.library/(all methods)
