# e-Grimoire 'the Book of Magics'
e-Grimoire is a multi-platform language creator/emulator based on 680x0 assembler compilation system containing both sub-routines and MACROS.

# How does it work ?
e-Grimoire is a game engine, accompanied by a set of routines and macros.
It can be used directly from MACRO Assembler such as Devpac/GenAm, but it can be used with the PARSER to emulate other programing languages.
