; This file is e-Grimoire documentation. It explains how the parser will create the Global Datas for a Source Engine project.

;**************************************************************
; 1. What does global data is ?
;------------------------------
;
; Global data is composed of all varialbes that are defined in the main source engine source code. These variables are reachable from
; everywhere in the project source code.


;**************************************************************
; 2. Global datas are variables are composed of :
;------------------------------------------------
;
;                1. primitives variables type such as : Integer, Floating number, String
;                2. Complex variables type such as : Static arrays (Dim) and Dynamic arrays of primitives
;                3. Objects (like memblocks)
;
; The list of availables variables types is available in the file : e-grimoire/Source Engine/Amiga68k/seVariablesTypes.s


;**************************************************************
; 3. How does the parser will create global datas ?
;--------------------------------------------------
;
; The first thing is that Parser will create 2 memory buffers :
;      a. The variables creation buffer (buffer #1)
;      b. the static Strings buffer (buffer #2)
; The second thing is that some MACROS will be push in the variables creation buffer (Buffer #1) :
;      - Insert "segDataReset"
; Once done the parser will implement the global datas during his pass to scan the whole source code.
; Each time it will encounter a new variable that is not inside a procedure (or function), it will add it in the buffer #1 this way :
;      - primitives Insert : addgVariable VARIABLENAME 
;      - Complexes Insert : addgCpxVariable VARIABLENAME
; If the variable is a String defined with direct Static String, the db.b reference will be added in the Static String buffer (buffer #2 ) this way :
;      - addgStaticString VARIABLENAME, DIRECTSTRING
